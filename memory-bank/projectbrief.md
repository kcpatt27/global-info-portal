# Project Brief

## Overview
The Global Information Portal is an interactive web application designed to provide comprehensive, easily accessible information about countries worldwide. It aims to be a central hub for users seeking geopolitical, demographic, economic, and other statistical data presented through an engaging map interface and detailed data panels.

## Core Requirements & Goals
- **Interactive Map Interface:** Provide a visually engaging world map (using D3.js/TopoJSON) allowing users to select countries easily.
- **Comprehensive Data Display:** Offer detailed country statistics across multiple categories (Geography, People, Economy, Energy, Military, etc.).
- **Data Visualization:** Implement charts and graphs for intuitive data interpretation and comparison.
- **Global/Regional Rankings:** Allow users to compare country metrics on a global and regional scale.
- **User-Friendly Navigation:** Ensure intuitive navigation between the map, information panels, and data tabs (Statistics, Rankings).
- **Responsive Design:** Deliver a seamless user experience across various devices, with a particular focus on mobile usability.
- **Maintainable Codebase:** Structure CSS and JavaScript for clarity, performance, and future development (ongoing refactoring efforts).
- **Data Source:** Utilize the World Factbook JSON API as the primary data source.
