# Product Context

## Why This Project Exists
To provide a centralized, interactive, and visually appealing platform for accessing and comparing comprehensive global country data, often fragmented across various sources.

## Problems It Solves
- Difficulty in finding consolidated, up-to-date country statistics.
- Lack of interactive tools for comparing countries visually (maps, charts).
- Need for a responsive interface to access global data on different devices.

## How It Should Work
Users interact primarily with a world map. Clicking a country reveals detailed information in dedicated panels. These panels contain tabs for statistics (current & historical) and rankings (global & regional). The interface should be intuitive, allowing easy filtering, searching, and comparison of data.

## User Experience Goals
- **Engaging & Interactive:** Make exploring global data fun and intuitive through the map and visualizations.
- **Informative & Clear:** Present complex data in an easily digestible format.
- **Efficient:** Allow users to quickly find the specific information they need.
- **Accessible:** Ensure usability across desktop and mobile devices, adhering to accessibility best practices.
- **Performant:** Provide a smooth experience, especially when loading data and interacting with the map/charts.
